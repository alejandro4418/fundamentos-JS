## 📌 Descripción del Proyecto
Este repositorio contiene la resolución del Laboratorio 3: **Introducción a JavaScript**. Para la aplicación práctica de los conceptos, el grupo seleccionó la página del videojuego **Skyfear** (alojado en **Game Jolt**), con el fin de simular la lógica de negocio, la gestión de datos, la manipulación del DOM y el almacenamiento local que tendría una plataforma de videojuegos real.
